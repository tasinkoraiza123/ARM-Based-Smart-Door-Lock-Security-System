# ARM-Based-Smart-Door-Lock-Security-System
Built and tested a PIN-based smart door lock integrating sensors and embedded hardware. Diagnosed a sensor malfunction that caused the system to misread motion at startup. Validated system reliability through repeated functional and edge-case testing.
